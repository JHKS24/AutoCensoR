# AutoCensor vNext Shortcuts

Shortcuts are editable in Settings > Shortcuts. The app normalizes common aliases
such as `Esc`/`Escape`, `Left`/`ArrowLeft`, `Right`/`ArrowRight`,
`PgUp`/`PageUp`, and `PgDown`/`PageDown`. Reset to Default Shortcuts restores
the table below. Conflict warnings show actions that share the same normalized
shortcut; resolve conflicts before relying on that key.

| Group | Action | Default |
| --- | --- | --- |
| Navigation | Previous image | `ArrowLeft` |
| Navigation | Next image | `ArrowRight` |
| Navigation | Original preview | `Tab` |
| Editing | Reset current image | `W` |
| Editing | Undo manual edits | `Ctrl+Z` |
| Editing | Redo manual edits | `Ctrl+Y` |
| Editing | Alternate redo | `Ctrl+Shift+Z` |
| Editing | Cancel / close transient UI | `Escape` |
| Editing | Brush | `B` |
| Editing | Restore Eraser | `X` |
| Editing | Detect Region | `D` |
| Editing | Stamp Tool | `E` |
| Editing | Rotate Stamp Clockwise | `R` |
| Editing | Rotate Stamp Counterclockwise | `Shift+R` |
| Editing | Quick Mask | `A` |
| Editing | Brush Size Down | `[` |
| Editing | Brush Size Up | `]` |
| Canvas | Reset zoom | `Home` |
| Canvas | Zoom in | `PageUp` |
| Canvas | Zoom out | `PageDown` |
| Canvas | Wheel zoom | Mouse wheel over canvas |
| Canvas | Pan while zoomed | `Space` + drag |
| Processing | Start automatic batch censoring | `F5` |
| Processing | Censor current image only | `F9` |
| PS toggles | Toggle tablet pressure | `1` |
| PS toggles | Toggle brush hardness | `2` |
| PS toggles | Toggle extended shortcuts | `3` |
| PS toggles | Toggle straight-line drawing | `4` |
| PS toggles | Toggle quickmask overlay | `5` |

Manual editing supports high-zoom cleanup with wheel zoom, Home/PageUp/PageDown
zoom shortcuts, visible zoom buttons, and Space+drag pan. Brush/stamp/restore
and manual region editing are user-facing editor tools, not backend-only
features.

In SFW Privacy Mode, original preview must be disabled or neutralized so it does
not reveal raw pixels.
